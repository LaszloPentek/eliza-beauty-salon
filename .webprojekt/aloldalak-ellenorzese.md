# Aloldalak ellenőrzése – 2026-11-04

Öt összekapcsolt demóoldal, azonos design system alapján. A gyökér index.html az új oldalra vezet, a koncepcióválasztó koncepciok.html néven maradt meg.

Sikeres programozott ellenőrzések: minden helyi kép-, script-, stílus- és oldalhivatkozás létezik; minden horgony célja létezik; egyedi azonosítók; oldalanként egy H1, szintkihagyás nélküli címsorok; öt különböző title és meta description; beolvasható JSON-LD; JavaScript szintaxis. A Kapcsolat oldalon egy űrlap van, az adatkezelési oldalon nincs. Mindegyik űrlap adatküldés nélküli demó.

A közös CSS az elfogadott kezdőoldalból lett kiemelve; a Tailwind CDN-függőséget eltávolítottuk. Google Fonts továbbra is külső erőforrás.

Vizuális böngészőteszt nem történt. A mobilos szabályok kódszinten rendelkezésre állnak; a képernyőn való megjelenés külön ellenőrizendő.
