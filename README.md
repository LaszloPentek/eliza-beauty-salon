# Eliza Beauty Salon

Statikus tanulmányprojekt; a bemutatott vállalkozás és kapcsolati adatok nem igazolt éles szolgáltatás.

## Megnyitás

Nyisd meg az public/index.html fájlt böngészőben. Nincs build vagy csomagtelepítés.

## Szerkesztés

A szövegek a HTML-fájlokban találhatók. A publikált fájlok a public/ mappában vannak; a docs/ a megőrzött briefet és arculati anyagokat tartalmazza.

## Publikálás

A meglévő /eliza-beauty-salon/public/index.html útvonal megmaradt; a gyökér index.html ide irányít.

## Rendrakás

2026-11-22: a korábbi koncepciók és a hozzájuk tartozó munkaanyagok helyi archívumba kerültek, majd kikerültek a repóból. A működő oldal erőforrásai megmaradtak. A HTML/CSS/JS és dokumentáció Prettier 3.6.2 formázást kapott.
